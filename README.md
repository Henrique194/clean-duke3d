# Clean Duke3D

Clean Duke3D is a source port of Duke Nukem 3D that focuses on modernizing
the original codebase and fixing long-standing bugs.

The project aims to provide a clean implementation of the Duke3D engine
while improving the portability of the code across modern platforms. Whenever
possible, it also leverages the accumulated experience of the Duke3D community
to enhance performance.
